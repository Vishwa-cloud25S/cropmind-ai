## Read this first — how these documents are honest

- **Market figures** are third-party published estimates, each with a link and the position
  stated at access date. Where reports disagree, we quote the *range* and name every source —
  we never cherry-pick the biggest number.
- **Projections and prices** are *indicative planning assumptions for validation* — they are
  not revenue, traction or commitment claims, and each is tagged `[assumption]` or `[source]`.
- **Current honest state (2026-09-28):** working MVP deployed publicly (live demo),
  a real evaluated model serving via AD-009 delivery, **0 paying users, 0 revenue,
  pre-incorporation**. Anything else would be a fabrication; none appears here.
- The same honesty rules as the product apply (see `docs/16-responsible-ai.md`): suspected
  findings only, paired evaluation figures, no chemical advice, demo clearly labelled.

## Why it is public

Endorsing bodies, partners and users can verify every claim against the repository itself —
the code, the evaluation reports, the deployment log (failures included), the model card.
That is the point: **files win over claims.**
